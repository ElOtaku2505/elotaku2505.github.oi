INTRODUCCIÓN

¿Qué es Prolog?

Prolog es un lenguaje de programación basado principalmente en el paradigma lógico. En lugar de indicar paso a paso cómo realizar una tarea, el programador describe hechos, reglas y relaciones que representan un problema.

Esta página presenta conceptos del paradigma funcional y del paradigma lógico para comprender sus características y diferencias.

01 FUNCTIONAL

Mónadas

Monads

Una mónada es una estructura que permite representar valores junto con un contexto y encadenar operaciones sobre ellos. Es común utilizarla para manejar efectos como errores, valores opcionales o estados.

PROLOG
resultado(X, Y) :-
    X > 0,
    Y is X * 2.

La idea principal es encadenar operaciones manteniendo el contexto del cálculo.

02 FUNCTIONAL

Funciones de Orden Superior

Higher-Order Functions

Son funciones que pueden recibir otras funciones como argumentos o devolver una función como resultado. Este concepto permite construir operaciones más flexibles y reutilizables.

PROLOG
aplicar(F, X, Resultado) :-
    call(F, X, Resultado).

doble(X, R) :-
    R is X * 2.

En Prolog, call/3 permite ejecutar un predicado recibido como argumento.

03 FUNCTIONAL

Evaluación Perezosa

Lazy Evaluation

La evaluación perezosa consiste en retrasar el cálculo de una expresión hasta que su resultado sea realmente necesario.

PROLOG
numero(1).
numero(2).
numero(3).

consulta(X) :-
    numero(X),
    X > 1.

Prolog utiliza búsqueda bajo demanda mediante consultas y backtracking, aunque su modelo de evaluación no es idéntico al de los lenguajes funcionales perezosos.

04 FUNCTIONAL

Inmutabilidad

Immutability

La inmutabilidad significa que un valor no se modifica después de haber sido creado. En programación funcional se busca trabajar con valores que no cambian.

PROLOG
persona(raul).

nombre(Persona, Nombre) :-
    Persona = raul,
    Nombre = "Raul".

Las variables de Prolog se comportan de una manera distinta a las variables imperativas: una vez instanciadas, no se reasignan.

05 FUNCTIONAL

Currificación

Currying

La currificación transforma una función que recibe varios argumentos en una secuencia de funciones que reciben un argumento cada una.

CONCEPTO
f(x, y)
↓
f(x) → g(y)

Prolog no utiliza la currificación como mecanismo principal, pero el concepto puede compararse con predicados que reciben argumentos progresivamente.

06 FUNCTIONAL

Clausuras

Closures

Una clausura es una función que conserva acceso a las variables del entorno donde fue creada, incluso cuando se utiliza posteriormente.

IDEA
crearFuncion(X)
        ↓
función + entorno
        ↓
resultado

Las clausuras son especialmente comunes en lenguajes funcionales como JavaScript, aunque Prolog posee mecanismos diferentes para representar relaciones y contexto.

07 LOGIC

Cortes /

Cut

El corte ! es un operador de Prolog que permite controlar el backtracking. Indica que ciertas alternativas anteriores ya no deben explorarse.

PROLOG
mayor(X, Y, X) :-
    X >= Y, !.

mayor(X, Y, Y) :-
    X < Y.

Cuando Prolog encuentra !, descarta determinadas alternativas de búsqueda relacionadas con esa regla.

08 LOGIC

Hechos

Facts

Los hechos son afirmaciones que representan información conocida. En Prolog se escriben normalmente como predicados terminados en punto.

PROLOG
animal(perro).
animal(gato).
animal(pez).

Estos hechos forman parte de la base de conocimiento de Prolog.

09 LOGIC

Reglas

Rules

Las reglas permiten expresar relaciones lógicas. Una regla establece que una conclusión es verdadera cuando se cumplen una o más condiciones.

PROLOG
padre(juan, pedro).
padre(pedro, ana).

abuelo(X, Y) :-
    padre(X, Z),
    padre(Z, Y).

La regla abuelo/2 puede encontrar relaciones de abuelo utilizando dos relaciones padre/2.

10 LOGIC

Unificación

Unification

La unificación es el proceso mediante el cual Prolog intenta hacer que dos términos sean iguales asignando valores a las variables cuando es posible.

PROLOG
?- X = juan.

X = juan.

En la consulta X = juan, Prolog unifica la variable X con el átomo juan.

11 LOGIC

Cláusulas de Horn

Horn Clauses

Una cláusula de Horn es una expresión lógica que contiene como máximo un literal positivo. Las reglas de Prolog se basan en este tipo de estructura lógica.

PROLOG
humano(raul).

estudiante(X) :-
    humano(X).

La estructura cabeza :- cuerpo representa una implicación lógica: si el cuerpo es verdadero, entonces la cabeza puede considerarse verdadera.

12 LOGIC

Backtracking

Vuelta atrás

El backtracking es el mecanismo mediante el cual Prolog retrocede en su búsqueda cuando una alternativa no produce una solución, probando otras posibilidades.

PROLOG
color(rojo).
color(azul).
color(verde).

?- color(X).

X = rojo ;
X = azul ;
X = verde.

Cuando el usuario solicita otra solución con ;, Prolog retrocede y busca otra alternativa disponible.
